# v0.5.0 — Text-first math expansion

Status: User-authorized implementation; release verification tracked separately.
Source baseline: `7b34b5be6e51983dd1e8f2c83bfeab3dcbb42776` (v0.4.0).
Design source: the user's approved 17-skill specification in the current conversation, with explicit authorization to implement and push. This repository document supersedes its draft ambiguities.

## Requirements and decisions

- Fresh/reset games: manual focus S01, counters off, automatic ceiling F01. Existing saved settings remain unchanged; do not reset earned progress or invent mastery of earlier skills.
- All 17 expanded skills are text/symbol-only, including hints and retry paths. Counter settings never enable counting beads on these skills.
- Bracelet collection, art, flight, rescues, platforming, energy, endings and existing introductory skills remain intact. Removing math counters does NOT remove collectible beads.
- Fractions must be stacked vertically with numerator, horizontal rule, denominator, and accessible spoken label. Use the same renderer in prompts, options, selected responses, results, and parent history. Slash notation is internal data only, not a visual fallback.
- One question per screen; numeric entry up to five digits. Selection buttons for comparison, ordering and fraction naming; keyboards 1–5 select choices in displayed order. Numeric choice indices are internal, never learner-facing answers.
- Preserve attempts/hints/rewards: wrong answers enter guided text support; completing the supported question then the original grants the existing reward once. No timer, new penalty, or mastery threshold added.
- Existing manual focus allows any selected skill, without a new lock. Existing automatic progression retains introductory prerequisites and appends the expansion sequence. The draft's suggested unlock order is a teaching sequence, not permission to lock previously accessible content.
- Bounded reproducible practice banks use existing least-exposure/spaced-retry sampling and retained evidence. Coverage means coverage of that bank, not of all mathematically possible problems. No new external dependencies.
