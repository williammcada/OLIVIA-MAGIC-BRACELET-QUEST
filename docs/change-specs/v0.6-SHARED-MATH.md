## Interface and behavior
Use the same mode labels and sequence: Mixed Review — General, Mixed Review — Targeted, Fixed Progression; Questions per gate (1–10); First grade; Last grade; optional 24-hour time; skill checkboxes with grade, name and standard; progression help; Save settings; progress/report and adult override. Extend grade choices to K–7. Settings remain available during play and during a gate. Validation must reject empty targeted pools and reversed/invalid ranges. Save changes for the next gate, preserving the current gate snapshot across home, settings and reload. Selection changes must not silently change an unfinished gate.

General/Targeted use shuffled skill bags; progression uses the latest ten first attempts, advances at >=80%, steps back to a linked prerequisite below 50%, and returns after prerequisite mastery. Earlier-grade prerequisite review is permitted. No hints, worked examples or automatic answer reveals, matching actual v0.5 reference (supersedes Olivia's guided scaffolds). Correct retries complete an item but cannot repair first-attempt evidence. At the end of the chosen range, continue the final skill; no unselected grade advance.

Use the same response-dependent on-screen keypad and physical keyboard support; no native keyboard required. Fractions are vertically stacked in prompt, answer preview, history and feedback; minus outside the fraction; powers superscript. Text only, no counting beads. Retain actual bracelet beads and all six adventures, rescues, cloud flight, audio and saved rewards.
